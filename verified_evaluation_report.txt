4. COMPARISON AND EXPLANATION OF REPORTED ACCURACIES (91.32% vs 89.26%)
================================================================================
Both previously reported numbers are genuine, mathematically verified results on the exact
same 242 held-out images and exact same model weights. Neither is fabricated or imagined.

Where each number originated:
  1) 91.32% (221/242 correct): Recorded in 'evaluation_results/evaluation_summary.json' by
     evaluate_model.py. It uses TensorFlow's native dataset loader (tf.data & tf.image.resize).
     This matches the exact preprocessing environment used during training.

  2) 89.26% (216/242 correct): Recorded in 'research_results/confidence_error_report.json' by
     confidence_error_analysis.py. It uses Python's Pillow library (PIL.Image.resize).
     This matches the single-image inference function in app.py and test_model.py.

Root Cause of the 5-Image Discrepancy (221 vs 216 correct):
  TensorFlow C++ JPEG decoding / resampling kernels use different coordinate centering,
  antialiasing, and sub-pixel rounding compared to Pillow's CPU bilinear filter.
  - Out of 242 test images, 237 images (97.9%) yield identical class predictions.
  - For exactly 5 borderline images, the slight sub-pixel rounding changes the top softmax argmax:
    * Image: cocci.1096.jpg (Ground Truth: Coccidiosis)
